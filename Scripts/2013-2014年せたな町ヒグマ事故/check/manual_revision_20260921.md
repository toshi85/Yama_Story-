# 2026-09-21 本人手動修正版（チャット貼付・途中まで）

2013年4月16日、北海道せたな町。
山菜を採りに山へ入った52歳の女性が、消息不明。

異変に気づいた夫が、山へ向かいます。
落ちていたのは、女性の衣服のみ。

捜索に出た人たちが見つけたのは、無残な姿となった女性でした。
現場に残された毛から、クマの遺伝子が調べられます。

けれども、その年に捕まったどのクマとも、一致しません。
一年後、また女性が襲われました。

襲ったのは、あの時のクマです。
なぜ、クマは捕まらなかったのか。
そして、探し続けたクマは、どこにいたのか。
地形図とともに解説します。

4月16日午前
北海道の南西部、日本海に面したせたな町。
町の北檜山区、52歳の女性が車で山へと向かいます。
目的は春の山菜採り。

正午

昼食の時間になっても帰らない妻を心配した夫は、
山のほうへと探しにいくことに。

すると、妻のワゴン車と衣服の一部が山で見つかります。
何か事件に巻き込まれたと判断した夫は、警察に通報。

到着した警察と消防は辺りを捜索。

午後1時45分ごろ

およそ車から200メートルほど離れた地点で妻を発見。
場所は、沢の近く。

女性は、体から血を流した状態ですでに息を引き取っていました。

両手両足の筋肉を食い取られており、見るに堪えない状況だったと言います。

遺体の周りには、クマの足跡が残っていました。
鈴やラジオなどの鳴り物や、身を守るための武器は一切持っていなかったと報告されています。

事態の深刻さを理解した北海道の行政は、周辺の町へ緊急の注意文書を送ることに。

送り先は、せたな町と奥尻町を除く管内の5町。電子メールで、女性が襲われた事故を知らせました。

翌日4月17日

北海道の研究機関「道総研」が、現地の調査に入ります。

周囲には、ちぎれた服が散らばっており、複数のクマの足あとが残っていました。

事故後の調査に派遣されたのは、檜山振興局の環境生活課と、道総研の道南地区野生生物室の研究者ら、合わせて3人。

町とせたな署から、事故について聞き取り調査をしたのち、人への危険が大きいクマによる事故と判断。

道総研は、現場に残っていたクマの毛を採取し、遺伝子を調べます。

一方、地元の猟友会は、早朝からクマを捜しに山へ入っていました。
しかし、クマは見つからないまま時間だけが流れます。

4月23日（事件から7日後）

檜山振興局に、町や警察、研究者など合計26人が集まり、クマ対策について話し合うことに。

現場の痕跡から、女性を襲ったクマはオスで、前足の幅は14センチと判明。

現場の近くには、クマを捕まえるためのわなを5カ所設置したことを伝えます。

さらに、最近捕獲されたクマと、現場に残った毛の遺伝子を照合するも、一致するクマはいなかったことも共有しました。

少しでも多く情報がほしい状況だったので、クマを目撃したときも、こまめに通報してもらうよう要請しました。

さらに、クマが住宅地へ近づきにくくなるよう、民家と山の境目に茂ったササを刈り取ることに。

小中学生を乗せるスクールバスも、家の玄関まで送り迎えし、最善を尽くしました。

また、会議では猟友会から、ハンターの高齢化が進んでおり、このままではクマの駆除が出来ないと主張もあがりました。

その問題に対処するため、狩猟免許の取得や猟銃を持つ許可、猟銃などの購入費も町が援助するよう変更。

こうして、いま出来る最善の手を打ち、事件を起こしたクマの捜索が続きました。

しかし、結局クマの捕獲はできず1年の歳月が流れました。

事件が起きた2013年の道南は、クマによる人の被害が道内の5方面で最も多かった地域。

函館新聞社の記事では、命を落とした人と、けがをした人は、合わせて3人。

クマの目撃情報は184頭で、負傷件数159件にのぼると公開。

2014年の春

昨年のクマ事件の状況を踏まえ、せたな町は事前にクマの捕獲準備を進めていました。

町長は事前にクマ駆除のための捕獲許可を受けていました。
なんとしても、去年のクマを捕獲することを目的にしていました。

そして、2014年に入り、クマの目撃情報が徐々に入り始めることに。

3月24日の厚沢部町での足跡発見の連絡。
そこから、4月4日までに、目撃や負傷の情報は5件となり、前年より3件多い数。

2014年4月4日。再び事件が発生。

せたな町で、またしてもヒグマによる人身事故が起きました。

前年の事故から、ほぼ1年後のことです。

今度の現場は、大成区の太田地区。
2013年の新成と同じ町にありますが、同じ地区で起きた事故ではありません。

捕獲に向けて準備していた町で、またしても人が襲われてしまったのです。

襲われたのは、45歳の女性。
山に入った目的は、前年の女性と同じ山菜採り。
ギョウジャニンニクという食べ物を求めていました。

女性は63歳の知人男性と二人で山へ入山。
事件当日の山の入口には、「クマ出没注意」の看板があったとされています。

午後2時ごろ
林道から約1キロ離れた山の中です。

クマが女性を襲ったのは、山菜採りから戻る途中。
男性が先頭、女性はその後ろを歩いていました。

すると突然、歩いてる女性の背後から、クマが襲いかかります。

クマがかみついたのは、女性の肩や腕に深く噛みつきます。

また、クマは、同行の男性にも向かってきました。

その時、男性がすかさず取り出したのが、ナタ。
枝を払う際に使う道具です。

向かってきたクマの体長は、およそ2メートル。
男性はナタで、クマの顔面を全力で攻撃。

傷つき出血したクマは観念し、そのまま山の中へと逃げていきました。

その後、女性はすぐさま病院へ緊急搬送。

肩や腕を深くかまれはしましたが、命に別状はありませんでした。
