# 別のPCで、せたな町の作り直し素材を作る指示（2026-09-25）

このファイルを、別のPCの Claude Code（または Codex）にそのまま渡してください。

---

せたな町ヒグマ事故（Yama_Story）の作り直し素材を作ってください。プロンプトは全部できていて、チェックにも合格しています。**プロンプトは一字一句そのまま使い、書き換えないでください**（書き換えると生成前のチェックが止めます。直す必要があると思ったら、作らずに理由を報告してください）。

## 1. 最新にする
- 親リポジトリ（`toshi85/Antigravity`、作業フォルダ `0/`）と `0/Yama_Story-/` の両方で `git pull`。
- 作業フォルダ: `Yama_Story-/Scripts/2013-2014年せたな町ヒグマ事故/素材_API_20260924/claude_audit_20260924/regen_20260925/`

## 2. 作るもの
- 一覧: `生成リスト.tsv`（ファイル名・種類・プロンプトのある資料）。この一覧にあるものだけを作る。一覧に無いものは作らない（お金と時間の無駄）。
- プロンプト: 一覧の「プロンプトのある資料」（Asset_Prompts_Fix2〜Fix5c.md）の、そのカットのブロックにある英語プロンプト。
- 固定人物: `CHAR_固定人物_20260925.md`。キャラのプロンプト先頭の `(CHAR-NN 再利用)` は、同じ人物として描くための印。**最初に CHAR-05〜10 の基準画像（全身・正面・背景透過）を1枚ずつ作り**、以後のキャラはその基準画像を参照画像として添えて作る（同じ人が別人にならないため）。基準画像は `CHAR-05.png` のような名前で作業フォルダの `images/` に置く。

## 3. 作る前のチェック（毎回）
```
cd Yama_Story-/System_Tools
python check_prompts_all.py "<資料.mdのパス>" --excerpt
```
合格票は親リポジトリで共有されているので、そのまま PASS になるはず。FAIL になったら作らずに報告。

## 4. 見本 → 本人の承認 → 残り
- 種類ごと（キャラ・背景・静止画・動画）に**1枚だけ**作り、本人に見せる。
- 本人が自分のターミナルで次を実行して承認する（AIは実行できない）:
  `python Yama_Story-/System_Tools/generation_gate.py approve "<資料.mdのパス>" --kind image`（動画は `--kind video`）
- 承認されたら残りを作る。

## 5. 作ったあとの点検（渡す前に必ず）
1. キャラは背景透過か: `python System_Tools/imagegen/check_handoff_folder.py <画像フォルダ>`
2. AIの画像点検（季節・同じ人か・台本の人物か・表情・地図にすべきか を見る）:
   `python System_Tools/imagegen/ai_image_review.py "<regen_20260925>/Asset_Prompts_Latest.md" --images <画像フォルダ> --out <出力フォルダ>`
   画像フォルダには固定人物の基準画像（CHAR-05.png など）も一緒に入れる（同じ人か見比べるため）。
3. 「直す」と出たものは作り直す（3回まで）。3回で直らなければ、そのカットを報告する。
4. 自分の目でも全部見る。特に: 4〜11月の場面に雪が無いか／同じ役（ハンター・職員・研究者・町長）が同じ人か／顔が見えて喜怒哀楽がはっきりしているか／キャラは3頭身か。

## 6. 渡し方
- ファイル名は `生成リスト.tsv` のとおり（ドライブの今の名前と同じ）。
- 本人の Google ドライブ「画像」フォルダ（https://drive.google.com/drive/u/0/folders/1e50euC7lBOkK8IYc1HdI9FaixuawvE3G）に入れる。古いファイルは Claude が先にゴミ箱へ移してある（`削除リスト.tsv`）。
- 終わったら、作ったファイルの一覧・作り直した回数・点検で残った気になる点を本人に報告する。

## やらないこと
- プロンプトの書き換え、一覧に無い素材の生成、動画の追加生成（キャラと背景で表すカットに動画は作らない）
- 予約投稿・YouTubeへのアップロード
