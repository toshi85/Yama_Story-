## 3. 作る前のチェック
- 6つの資料（Fix2〜Fix5c）とも、今の中身で合格した記録が親リポジトリの `.claude/yama_gate/prompt_checks/` に入っている。`git pull` すればそのまま生成できる。
- 確かめたいときは Fix5a〜5c だけ、受け入れ理由つきのスクリプトで回す（数分かかる）:
  `cd <作業フォルダ> && python -X utf8 run_fix5_checks.py 5a`（5b・5c も同じ）→「総合判定: PASS」になる
- Fix2〜Fix4 は理由つきの合格記録が既にあるので回さない（理由なしで回すと FAIL と出る）。
- 生成が「合格記録が無い」で止まったら、プロンプトを変えずに報告。

## 4. 見本 → 本人の承認 → 残り
- 種類ごと（キャラ・背景・静止画・動画）に**1枚だけ**作り、本人に見せる。
- 本人が自分のターミナルで次を実行して承認する（AIは実行できない）:
  `python Yama_Story-/System_Tools/generation_gate.py approve "<資料.mdのパス>" --kind image`（動画は `--kind video`）
- 承認されたら残りを作る。

## 5. 作ったあとの点検（渡す前に必ず）
1. キャラは背景透過か: `python System_Tools/imagegen/check_handoff_folder.py <画像フォルダ>`
2. AIの画像点検（季節・同じ人か・台本の人物か・表情・地図にすべきか を見る）:
   `python System_Tools/imagegen/ai_image_review.py "<作業フォルダ>/Asset_Prompts_Latest.md" --images <画像フォルダ> --out <出力フォルダ>`
   画像フォルダには固定人物の基準画像（CHAR-05.png など）も一緒に入れる（同じ人か見比べるため）。
3. 「直す」と出たものは作り直す（3回まで）。3回で直らなければ、そのカットを報告する。
4. 自分の目でも全部見る。特に: 4〜11月の場面に雪が無いか／同じ役（ハンター・職員・研究者・町長）が同じ人か／顔が見えて喜怒哀楽がはっきりしているか／キャラは3頭身か／ナレーションで言っている人や物が画面に写っているか。
