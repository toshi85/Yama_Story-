あなたの仕事は、内蔵の画像生成ツール（image_gen）で7枚の画像を作って保存することだけです。コードの変更・git・Web検索・APIキーの利用はしません。

入力: このフォルダの `image_queue_codex.json`（[{id, prompt}, ...] の7件）。

手順（1件ずつ。まとめて生成・まとめて保存はしない。並列にしない）:
1. JSON の順番どおりに1件取り出す。
2. その `prompt` を一字一句そのまま（言い換え・追記・削除なし）内蔵の image_gen に渡して1枚生成する。id が `_char` で終わるものは正方形、それ以外は横長16:9。
3. 生成された画像ファイルを、すぐに `images_codex/<id>.png` へコピーして保存する（例: images_codex/ASSET-180_still.png）。
4. 保存したファイルの幅・高さを確かめ、`images_codex/log.tsv` に「id<TAB>元ファイルのパス<TAB>幅x高さ<TAB>OK/NG」を1行追記する。_char なのに横長、_still/_bg なのに正方形なら NG と書く。
5. 次の1件へ進む。

生成を断られた場合は、プロンプトを変えずに1回だけやり直し、それでも駄目なら log.tsv に REFUSED と書いて次へ進む。
最後に log.tsv の中身を表示して終わる。
