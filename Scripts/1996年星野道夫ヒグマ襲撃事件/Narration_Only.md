### §1. フック

ある湖の畔に、世界で最もヒグマを愛した男がいました。

銃を持たず、ヒグマと正面から向き合ってきた写真家、星野道夫（ほしの みちお）さん。

アラスカに18年。極北の大地で、命の営みを撮り続けてきた人物です。<!-- src: ja.wikipedia 星野道夫 / nippon.com James Singleton 2016-08-08 -->

そんな星野さんが、1996年8月、ロシア・カムチャッカ半島でヒグマに襲われます。<!-- src: ja.wikipedia 星野道夫 1996-08-08 -->

なぜ、ヒグマを最も理解していたはずの写真家が、襲われることになったのか。

そしてその裏には、人間の手によって変えられた1頭のヒグマの存在がありました。地形図とともに解説します。

### §2. 星野道夫さんとカムチャッカ取材

星野道夫さん、当時43歳。<!-- src: ja.wikipedia 1952-09-27生まれ -->

アラスカの野生動物と先住民を、18年にわたって撮り続けてきた動物写真家です。1989年には日本の写真家として権威ある木村伊兵衛写真賞を受賞しています。<!-- src: ja.wikipedia 木村伊兵衛賞1989 / nippon.com -->

そんな星野さんの撮影地として選ばれた場所が、ロシア・カムチャッカ半島の南端にあるクリル湖でした。

7600年前の大規模噴火によって生まれた、径7キロのカルデラ湖。<!-- src: 北大ラボエッセイ クリル湖 https://hokudai-koko.sakura.ne.jp/essays/e003/ -->

600頭から800頭ともいわれる、世界有数のヒグマ密度を誇るヒグマの楽園です。<!-- src: 北大ラボエッセイ クリル湖 / en.wikipedia Kuril Lake -->

取材の目的は、TBSテレビ「どうぶつ奇想天外！」のロケ。「ヒグマと鮭」というテーマで、星野さん自身が持ち込んだ企画でした。<!-- src: ja.wikipedia / excite.co.jp こじへい 2016-05-01 -->

同行したのはTBSスタッフ3名と、現地のロシア人ガイド兄弟2名。合わせて6名のチームです。<!-- src: ja.wikipedia / en.wikipedia Igor Revenko / note 秋田しげと 2023-02-04 「ガイドは兄弟」 -->

### §3. 7月25日、カムチャッカ到着

1996年7月25日。

一行はモスクワを経由して、カムチャッカ半島の中心都市ペトロパブロフスク・カムチャツキーに到着します。

そこからヘリコプターに乗り換え、南カムチャッカ自然保護区の中にあるクリル湖へと入りました。

クリル湖は、湖の周囲を急峻な山と原始の森に囲まれた、人間がほとんど立ち入らない秘境です。

撮影拠点は、湖の南東岸・シユシュク岬にある、丸太造りの狩猟ロッジ。実は、高床2階建ての、しっかりとした建物でした。<!-- src: en.wikipedia Cape Siyushk / travelaficionados Kuril Lake / note 秋田しげと 2023-02-04 「ロッジ・高床2階建て」 -->

スタッフ全員がこの小屋で寝起きする中、星野さんだけは小屋から数メートル離れた場所に、ひとりテントを設営します。<!-- src: ja.wikipedia 星野道夫 / president.jp 中野タツヤ 2026-01-03 -->

ヒグマと自然の中で寝起きすることが、星野さんにとっては撮影の一部だったのです。<!-- src: times.abema.tv 星野道夫銃を持たない理由 -->

### §4. 7月27日、深夜の警告

7月27日。到着から2日後の夜。

星野さんのテントの近くに、もう一人、ある米国人写真家がテントを張っていました。<!-- src: ja.wikipedia 星野道夫 -->

真夜中、米国人写真家は金属がぶつかる音で目を覚まします。

テントの外に出てみると、小屋の食糧庫の屋根に、1頭の巨大なヒグマがよじ登っていたのです。<!-- src: ja.wikipedia 星野道夫 -->

体長2メートルを超え、体重はおよそ250キロ。雄の巨大なヒグマでした。<!-- src: ja.wikipedia 加害個体描写 -->

そして、その額には特徴的な赤い傷がありました。<!-- src: ja.wikipedia -->

米国人写真家は大声を上げ、手を激しく叩きました。ヒグマは屋根から降りると、なんと、星野さんのテントの背後へと回り込みます。<!-- src: ja.wikipedia -->

米国人写真家は、テントから顔を出した星野さんに向かって、こう叫びます。

「あなたのテントから、3メートルにヒグマがいる」<!-- src: ja.wikipedia 7/27 米国人写真家の警告 -->

米国人写真家はすぐに小屋へ走り、ドアを叩いてガイドに通報しました。<!-- src: ja.wikipedia -->

駆けつけたガイドは、クマ除けスプレーを噴射します。しかし、距離が遠すぎて、ヒグマには届きませんでした。<!-- src: ja.wikipedia -->

そしてガイドは、星野さんに小屋で寝るよう強く説得します。

しかし、星野さんはこう答えたといいます。

「この時期はサケが川を上って食べ物が豊富だから、ヒグマは襲ってこない」<!-- src: ja.wikipedia 星野道夫 / president.jp 中野タツヤ 2026-01-03 -->

18年間、アラスカでヒグマと共に過ごしてきた経験が、その確信を支えていました。

### §5. 「サケが豊富だから襲わない」確信の根拠

星野さんの確信には、確かな根拠がありました。

普通のヒグマは、サケや木の実、草の根といった野生の食べ物が豊富な時期、人間を襲うほどの必要性を持ちません。

星野さん自身、著書の中でこう書いています。

「はじめから人を襲おうとするクマは、まずいない」<!-- src: 星野道夫『アラスカ 光と風』六興出版 1986 / abematimes 星野道夫銃を持たない理由 -->

クマは人間を避けたい。人間を怖いとさえ思っている、というのが星野さんの信念でした。

そしてその信念のまま、星野さんはテントに戻って眠りにつきます。

### §6. 8月6日、ヒグマ再出現

8月6日。深夜。

同じヒグマが、もう一度、撮影地に姿を現します。<!-- src: ja.wikipedia 8/6 再出現 -->

ガイドは再びクマ除けスプレーで追い払いました。

しかし、明らかに普通ではない出来事です。

同じヒグマが、2回も、人間の生活圏に踏み込んできた。

通常、野生のヒグマは人間を見ると距離を取ります。それが、警戒心を失っていたのです。

それでも、星野さんはテントでの撮影を続けました。

後悔の念は、一切なかったといいます。<!-- src: en.wikipedia Nick Jans証言 「Hoshino only smiled at warnings」 -->

### §8. クルーの叫び、ガイドのシャベル

スタッフは「ベアー！ベアー！」と叫び続けます。

ガイドは、シャベルを手に取り、地面を激しく叩きつけてヒグマを威嚇しました。<!-- src: ja.wikipedia 襲撃直後のガイド対応 -->

ヒグマはその音に顔を一度上げました。しかし、それだけです。

大声を出しても、シャベルを叩きつけても、ヒグマは恐れる素振りを一切見せなかったのです。

そしてヒグマは、星野さんを抱えるようにして、湖畔の森の中へとゆっくりと姿を消しました。

残されたスタッフは、現場に立ち尽くすことしかできませんでした。

### §9. ヘリコプターと、解剖

その日のうちに、武装したハンターとシニア研究者を乗せたヘリコプターが、現場に飛来します。<!-- src: en.wikipedia Mosolov senior researcher -->

上空からヒグマを捜索します。発見されたヒグマは、ヘリコプターに向かって、なんと、攻撃的に突進してきたといいます。<!-- src: en.wikipedia 加害個体の攻撃行動 -->

通常、野生のヒグマはヘリコプターの音と気配で、すぐに森の奥へ逃げ込みます。

それが、ヘリコプターに攻撃を仕掛けてくる。極めて異常な行動です。<!-- src: en.wikipedia atypical aggressive behavior -->

ヘリコプターから、ヒグマは射殺されました。

そして地上で行われた解剖では、ヒグマの胃の中から、人間の遺品が確認されたのです。<!-- src: en.wikipedia 解剖結果・胃の内容物 -->

額に赤い傷のあった巨大なヒグマこそが、星野さんを襲った個体であったことが、これで確定しました。

### §10. 加害個体の正体

なぜ、このヒグマは人間を恐れなかったのか。

後の検証で、ある重大な事実が明らかになります。

このヒグマは、人間によって餌付けされ、警戒心を失っていた個体だったのです。<!-- src: ja.wikipedia 餌付け説 / yamaoji 2008-06 Food Conditioned解説 / en.wikipedia Igor Shpilenok証言 -->

クリル湖の周辺では、観光や撮影を目的として、ヒグマに食物を与える行為が行われていたとされます。<!-- src: en.wikipedia Igor Shpilenok証言 / yamaoji Food Conditioned / note 秋田しげと 2023-02-04 -->

ロシアの野生動物写真家、イーゴリ・シュピレノクさんは、こう証言しています。<!-- src: en.wikipedia Igor Shpilenok証言 -->

「無責任な写真家や映像作家たちによって、餌付けされていた」

撮影しやすいように、近距離まで呼び寄せるためです。

しかしその行為は、ヒグマの本能を、決定的に変えてしまっていました。

そしてもう一つ、見逃せない指摘があります。<!-- src: note 秋田しげと 2023-02-04 -->

餌付けはTBSが到着する直前に、入れ替わるように中止されたと考えられています。

それまで人間の食べ物にありついていた1頭は、急に「餌」が消える事態に直面します。

飢えと、人間の食べ物の記憶。その組み合わせが、ヒグマの攻撃性を、さらに極端な方向へ追い込んだ可能性も指摘されています。<!-- src: note 秋田しげと 2023-02-04 -->

**字数: 676字**

### §11. Food Conditioned ―食物条件付け―

動物学の世界には、「フード・コンディションド」という言葉があります。<!-- src: yamaoji.cocolog-nifty 2008-06 / en.wikipedia food conditioning -->

人間の食べ物の味を覚え、人間を「食料源」と認識してしまった個体のことです。

食物条件付けされたヒグマは、本来の警戒心を完全に失います。

大声を上げても、シャベルで地面を叩いても、ヘリコプターが上空に来ても、恐れることがありません。

ヒグマの記憶力は、犬の数倍とも言われます。

一度「人間は食料」と覚えてしまうと、その記憶はなかなか消えません。

星野さんを襲った1頭は、まさに、その典型でした。

**字数: 293字**

### §12. 10年かかった、真相の究明

しかしこの「餌付けされた個体だった」という事実が明らかになるまでには、長い時間がかかります。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』山と渓谷社 2006 / note 秋田しげと 2023-02-04 -->

星野さんの友人や、クマを長年研究してきた科学者たちが、独自に検証を進めます。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』2006 -->

そして事件から10年後の2006年、ようやくその全貌が、書籍として明らかにされます。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』山と渓谷社 2006 -->

「あの夜、ヒグマを呼び寄せていたのは、人間の手だった」

1つ目。当時、サケの遡上は例年の10分の1まで落ち込んでいたという事実。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』2006 -->

星野さんは「いい写真が撮れない」と、米国人写真家にこぼしていたといいます。

2つ目。ヒグマの行動原理に反する点。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』2006 -->

通常、ヒグマはテントそのものを襲うのではなく、テント内の食料の匂いに引き寄せられて来ます。

星野さんは野生動物の専門家として、テント内に食料を一切置かない徹底ぶりを貫いていました。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』2006 -->

にも関わらず、ヒグマはまっすぐにテントを襲った。

3つ目。星野さんが「テントで一人寝た」とされる経緯。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』2006 -->

米国人写真家の証言によると、小屋には機材が多くてスペースがなく、星野さんは小屋に入ることができなかったとされています。<!-- src: 小坂洋右・大山孝広『星野道夫 永遠のまなざし』2006 / note 秋田しげと -->

「無謀にもテントを選んだ」という当初の報道とは、まるで違う背景がそこにあったのです。

10年かけて、ようやく辿り着いた真実です。

### §13. 銃を持たないという哲学

ここで、星野道夫さんという人物について、もう少し深く掘り下げる必要があります。

星野さんは、生涯、撮影に銃を持っていきませんでした。<!-- src: times.abema.tv 星野道夫銃を持たない理由 / モデルプレス -->

その理由について、星野さんはこう語っていたとされます。<!-- src: times.abema.tv 星野道夫銃を持たない理由 -->

「銃を持っていくということは、自然に対してどこか変な大胆さが出てきて、あんまり考えなくなる」

「銃を持っていない時は、自然に対して少し謙虚になれる」

銃を持たないことが、自然と向き合う姿勢そのものでした。

自然を尊重するからこそ、自分は弱い立場でいる。それが、星野さんの哲学でした。

### §14. アラスカへ、18年の旅

星野さんは、千葉県市川市の出身です。<!-- src: ja.wikipedia 1952-09-27 千葉県市川市南八幡 -->

19歳の時、神田の古本屋でナショナルジオグラフィックを手に取ります。<!-- src: nippon.com James Singleton 2016-08-08 / ja.wikipedia -->

その雑誌に載っていた1枚の写真に、星野さんは強く惹きつけられます。アラスカ・シシュマレフ村の写真でした。

星野さんは思い切って、村の村長宛に1通の手紙を書きます。<!-- src: nippon.com / ja.wikipedia -->

数ヶ月後、返事が届きます。そして星野さんは、ひとりでシシュマレフ村に3ヶ月滞在することになりました。

慶應義塾大学を卒業した後、動物写真家・田中光常さんに2年師事します。<!-- src: ja.wikipedia 田中光常師事 -->

そして1978年、アラスカ大学フェアバンクス校に入学。そのままアラスカに移り住み、18年間にわたって、極北の自然を撮り続けることになります。<!-- src: ja.wikipedia 1978年アラスカ大学入学 / nippon.com -->

### §18. 「地球交響曲第三番」―死後に届いた言葉―

星野さんは、亡くなる直前まで、ある映画の出演を予定していました。<!-- src: ja.wikipedia 地球交響曲第三番 / eiga.com 1997-10-10公開 -->

龍村仁（たつむら じん）監督による、ドキュメンタリー映画『地球交響曲 第三番』。<!-- src: ja.wikipedia 龍村仁監督 -->

撮影が始まる、その直前に、星野さんの訃報が届きます。

### §21. 教訓

星野道夫さんが命を落としたカムチャッカの事件は、私たちに、3つのことを、静かに問いかけています。

1つ目。人間に餌付けされたヒグマは、もう、野生のヒグマではない、ということ。

食物条件付けされた個体は、警戒心も、本能的な距離感も失っています。経験豊富な人間でさえ、対処できないのです。

2つ目。野生動物を撮影する時、近づきすぎてはいけない、ということ。

観光のため、撮影のために、人間が動物を近距離まで呼び寄せると、その動物だけでなく、後から来る人間の命まで、危険に晒すことになります。

3つ目。警告を、受け取ること。

7月27日の夜、星野さんは確かに、警告を受け取っていました。

しかし、長年の経験と確信が、その警告を「特別な事態ではない」と判断させてしまいます。

経験が深い人ほど、警告を受け取った時に、立ち止まる勇気が必要なのかもしれません。
