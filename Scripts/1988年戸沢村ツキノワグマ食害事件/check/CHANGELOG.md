  絵ごとに決まる値を中央値でならすと、構図の都合を癖と読み違えるうえ、
  頭の位置から吹き出しの側を決めるといった**自動判定を上書きしてしまう**。

  - `move_sec` … `build_shots.py:449` が6通りへ散らし、さらにカットの尺に縛られる＝好みでなく算数
  - `bubble_dx`／`bubble_dy` … `render.py` が頭の位置・目の高さ・体との重なりから1カットずつ計算
  - `bubble_side` … `render.py:567` の `to_left = hx > ch.width*0.5` ＝頭が絵のどちら側にあるかで自動決定
  残したのは `base_y`／`amount`／`scale`／`bubble_delay`／`bubble_text_dx`／`bubble_text_dy`
  （いずれも `build_shots` がカットごとに散らしていない＝全カット共通の値であることをコードで確認済み）。
  `--report` に「わざと覚えない項目」の節を追加。**項目を足すときはこの物差しに掛けてから足すこと**

## 2026-09-02

- **手直しの自動学習**（`learn.py`・本人の要望「わざわざ学習してと言わなくても自動的に学習するシステムに」）—
  検収シートで直した**差分**を覚えて、次の企画の既定値にする。頼まなくても動く。
  取り込みの入口は3つ＝「この調整を保存」「送信」（`serve_check.py`）／「下書きを作り直す」（`quick_rebuild.py`）／
  「動画を作る」の先頭（`make.py`）。当てるのは `make.py` の **build_shots のあと・quick_rebuild の前**
  （素の既定 → 企画をまたいだ癖 → この企画の手直し、の順で後ほど強い）。
  置き場は `~/.cache/yama-edit/learned.json`（素材フォルダの外。企画をまたいで貯めるため）
  - 覚えるのは**出来上がりの値でなく差分**。癖は差分にしか出ない
  - **動きの型は既定値にしない**。人がそこから逃げている型を回転から外すだけ
    （型を1つに寄せると量産型に見える＝`CHAR_MOVES` を回す意図を壊さない）
  - 適用の線＝**5回以上 かつ 同じ向きが70%以上**。ばらついているものは記録だけして当てない。
    項目ごとにずらし量の上限があり、1回の極端な直しで全体が壊れない
  - 言葉の修正メモは自動では当てない。繰り返されたものを `--report` に出す（道具側を直す候補）
  - 見る・消す＝`learn.py --report` / `--status` / `--forget <項目>` / `--reset`
- **学習用に機械可読の差分を残す**（`sheet.js` の `rawDelta`）— 履歴の `changes` は日本語の表示文字列なので、
  `delta: {項目: [前, 後]}` を併記する。古い履歴は表示文字列からも読める（後方互換）
- 🚨**Windows で `--report` が落ちるのを直す** — コンソールの既定が cp932 で、`✅` を print すると
  `UnicodeEncodeError`。試験で実際に落ちた。`learn.py` は読み込み時に stdout を UTF-8 へ付け替える。
  ⚠️ 同じ書き方（絵文字を print）は `make.py` など他の道具にも残っている＝未対応
- 🚨**動きの型を表示名のまま覚えていたのを直す** — 古い履歴には内部名（`step_back`）でなく
  表示名（`後ずさり`）が入っている。そのまま覚えると `shots.json` と一致せず、
  **「外した」と報告されるのに1カットも外れない**（＝嘘の報告になる）。対応表で内部名に直し、
  読めない型は覚えない。レガシー履歴からの適用まで実データで確認済み
