# 別のパソコンで編集の続きをする（2026-09-10 版）

## 用意するもの

**道具**は GitHub から取ります。ターミナルで次を実行してください。

```
git clone https://github.com/toshi85/Antigravity.git
```

すでに持っているなら `git pull` で最新にします。9月10日の修正が入ります。

**素材**は Releases から取ります。GitHubに本人のアカウントでログインし、
[Releases一覧](https://github.com/toshi85/Yama_Story-/releases) の
「戸沢村：画像311枠・全編編集確認セット」を開いてください。

| そのPCの状態 | 落とすもの |
|:---|:---|
| はじめて使う | `Tozawa_Edit_Materials.zip` と `Tozawa_Edit_Review.zip`（計1.6GB）を展開し、そのうえで下の差分を上書き展開 |
| 9月7日のセットが入っている | 差分の zip だけ。既存の `Tozawa_Edit` フォルダへ**上書き**で展開 |

差分の zip は `Tozawa_Edit_差分_<日時>.zip` という名前です。展開すると `Tozawa_Edit`
フォルダができるので、既存のものと同じ場所へ重ねてください。フォルダ全体を移動でき、
元のパソコンの絶対パスは要りません。

## 開き方

Macは `編集を開く.command`、Windowsは `編集を開く.bat` を開きます。Python 3 が要ります。
初回は必要な環境をそろえます。専用ツールがブラウザに開き、各カットの調整と再生ができます。

すぐ動画を見るなら `out.mp4`。全カットの一覧は `check/sheet.html` です。

## 9月10日に変わったこと

**カット20が実写になりました。** 衣服がボロボロで、血は描いていません。

**画面の作りが変わりました。** AIが作業しているカットはその行が光り、質問されたときは
そのカットの下に返信欄が出ます。まだ動画に入っていない直しはオレンジの枠で「未反映」と
出て、その場で反映できます。

**直したのに動画に入らない不具合を直しました。** 9月10日まで、部分差し替えが1コマのずれで
黙って止まり、修正が動画に届かないことがありました。いまは終わったあとに自動で確認し、
入っていなければ作り直します。

## 気をつけること

**AIへの修正依頼にはそのPCでのログインが要ります。** 閲覧と手動の調整だけなら要りません。
追加の有料生成は、操作しない限り発注されません。

**大きな画像をそのまま開かせないでください。** 9月10日に、AIが生成画像を23枚読み込んで
会話が13MBまで膨らみ、23分間止まりました。いまは300KBを超える画像を開こうとすると
機械的に止まり、縮小版を作る手順が出ます。

**仮の機械音声を使った確認版です。** 本人の最終確認と本番音声の差し替えは未実施です。
残る確認箇所は `編集確認メモ.md`、自動検査の結果は `check/GATE.md` を見てください。
