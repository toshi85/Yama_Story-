| 事実 | 出典 | 不採用の理由 |
|:--|:--|:--|
| 大字名（神田・古口・権現山）の読み仮名 | 県／事件簿 | 「じんでん」等の読みが検索要約でしか裏取りできず未確認。ナレーションでは距離（500m・5km）で語る |
| 加害グマは「体長145cm・体重100kgのオス」 | 事件簿 | 米田（現地に3回入り資料も入手）の「140cm・84kg・4歳」と食い違う。一次に近い米田を採用 |
| 「加害グマは集落で飼われていた個体だった」という噂 | 事件簿の記述 | 出所が特定できない。噂として紹介しても検証手段がない |
| 頭骨の矢状稜が潰れている／富樫邦男氏が所有 | 文春 | 記事の写真は転載不可。所在と撮影許諾が未確認。映像化の目処が立たない |
| 「軽トラがぶつかっても電車がぶつかっても死なない」 | 文春の見出し | 見出しの表現で、本文の該当記述を特定できていない |
| 2026年5月の被害者の氏名 | 読売の英訳経由 | 機械翻訳を介した固有名詞で未確定。実名は使わない |
| 山形県の「特別警報」導入検討 | 山形NEWSチャンネル 2026-05-28 | 動画タイトルのみで本文未確認。検討段階であり結論が不明 |
| 2章の事故発生状況・曜日別の分析 | 米田2 p.49 | 面白いが本件と接続しない。尺を圧迫する |
