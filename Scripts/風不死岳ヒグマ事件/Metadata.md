# 風不死岳ヒグマ襲撃事件 メタデータ

## タイトル
【山岳遭難事故】次々とエサにされる人々、、1976年風不死岳ヒグマ襲撃事件

## 概要欄

1976年6月、北海道・風不死岳（ふっぷしだけ）。
ヒグマ出没の警報が出ているにもかかわらず、4家族11人がタケノコ採りのために入山。
笹藪の中でバラバラに散った彼らを、1頭の若いヒグマが次々と襲います。

6日間で3度の襲撃。仲間がそばにいた人は助かり、1人きりだった人は帰れませんでした。

この動画では、事件の全容を時系列で解説し、
なぜ警報が無視されたのか、なぜ被害が拡大したのかを検証します。
