> 2026-09-15 新設・本人承認。戸沢村の追加素材で本人が指摘した内容に、これまでの決まりと起きやすい抜け漏れを足した。本人の新しい指摘は、同じセッションでここに足す。
> 出どころ: 今＝2026-09-15の本人指摘／決＝これまでの決まり／案＝Claudeが足した項目

## 担当と手順

1. 先に `check_handoff_folder.py` を通す（背景透過・フォルダとチェックリストの一致は機械で止める）。
2. **Sol（gpt-5.6-sol / medium）が全カットを見る。** 各カットの画像・ナレーション1行・制作メモ（シーン・プロンプト・編集者指示）と、前後のカットを並べて、下の項目に当たるかを判定する。**迷ったら挙げる**（見逃しより挙げすぎを選ぶ）。出力は「カット番号／項目番号／理由1行」の一覧。
3. **Astra（gpt-6-astra / medium）は、Sol が挙げたカットだけを詳しく見る。** 本当に直すべきか、直すならプロンプトをどう直すかまで書く。
4. Claude は Astra の結果を読み、本人に渡す一覧（直したカット・直さなかった理由）を作る。
5. 最初の1作品では、本人のチェック結果と Sol が挙げたカットを突き合わせ、Sol の見逃しを数えて記録する。見逃しがあれば、その項目の書き方を直す。

### 実行コマンド（2026-09-16 追加）

`python3 System_Tools/imagegen/ai_image_review.py <Asset_Prompts_Full.md> --images <画像フォルダ> --out <出力フォルダ>` で、Sol の全カット確認 → Astra の詳細確認 → 本人向けの `一覧.md` までを1回で回す。途中で止まっても同じコマンドで続きから再開する。呼ばずに中身だけ確かめるときは `--dry-run`。本人の指示で変えた内容は、先に Asset_Prompts_Full.md へ反映する（画像がプロンプトより新しいと止まる。2026-09-16 の試運転で、9/13 の古いプロンプトを基準にして、本人が決めた変更4件を「直す」と誤判定した）。
