# 画像を作る準備（受講生向け）

やることは**2つだけ**です。あとは全部AIがやります。

## 1. Codexに、この一文を貼る

```
imagegen/run.py を使って、<作品フォルダ> の画像を全部作ってください。
途中で生成の上限に当たっても止めず、解除されたら続けてください。
```

## 2. 開いたChromeでChatGPTにログインする（最初の1回だけ）

普段のChromeとは別のウィンドウが開きます。いつものアカウントでサインインしてください。
Cookieは残るので、2回目からは何もしなくて済みます。

---

これで終わりです。あとは画像がそろうまで自動で進みます。夜のあいだも動きます。

## 途中で止まったように見えたら

**画像生成には1日あたりの上限があります（ChatGPT Plusで約90枚）。**
長い動画1本ぶんの画像は、それを超えるので**数日かかります**。故障ではありません。

上限に当たると、解除までの残り時間を読み取って待ち、**空いた瞬間に自分で再開します**。
何もしなくて構いません。

進み具合は、作品フォルダの `images/` に入っている画像の枚数がそのまま答えです。

## Chromeのウィンドウを閉じてしまったら

Codexにこう言ってください。

```
imagegen/run.py をもう一度動かしてください。
```

**どこまで進んだかは画像そのものが覚えている**ので、続きから再開します。
やり直しにはなりません。

---

## 中で何が起きているか（読まなくても使えます）

- 自動化専用のChromeを、外から操作できる状態で開きます。普段のChromeには触りません
- ChatGPTの画面に生成の段取りを流し込み、1枚ずつ作らせます
- 出来た画像を作品フォルダへ移します
- 上限・エラー・ページの再読み込みは、全部それ自身が処理します

人の手が要るのは、**最初のログイン1回だけ**です。
