# 画像を作る準備（受講生向け・macOS／Windows）

## 最初に1回だけすること

1. お使いのOSのランチャーをダブルクリックします。
   - macOS: `start_imagegen.command`
   - Windows: `start_imagegen_windows.bat`
2. 画像を作る作品フォルダを選びます。
3. 自動化専用Chromeが開いたら、ChatGPTへログインします。

以上です。設定完了後はターミナルを閉じて構いません。専用Chromeは画像がそろうまで開いたままにしてください。普段使っているChromeは、これまでどおり使えます。

ランチャーに作品フォルダをドラッグ＆ドロップしても開始できます。

## 自動で設定されるもの

- `Asset_Prompts.md` から生成キューを作成（すでにキューがあれば再利用）
- 通常のChromeとは別の、自動化専用プロファイルを作成
- Chromeの「複数ファイルを常に許可」を専用プロファイルだけで有効化
- 保存先を作品フォルダの `images/` に固定
- パソコンへのログイン後に自動再開する設定
- 二重起動の防止
- 生成上限の待機と、解除後の自動再開
- エラー終了時の自動再起動

Codexの「常に許可」や、Chrome設定画面の変更は必要ありません。

## 人が行う必要があること

ChatGPTへの初回ログインだけです。アカウント認証は安全上、自動化できません。ログイン情報は自動化専用Chromeに保存されるので、通常は2回目以降不要です。

Google Chromeと、画像生成を利用できるChatGPTアカウントも必要です。アカウントのプランや利用上限を、このツールが変更することはありません。

## 進み具合

作品フォルダの `images/` にあるPNGの枚数が進捗です。ログは作品フォルダの `.imagegen/imagegen.log` にあります。

画像生成の利用上限に達した場合は、解除まで待って自動再開します。数日かかることがありますが、故障ではありません。

## 専用Chromeを閉じてしまった場合

お使いのOSのランチャーをもう一度実行してください。保存済み画像を数えて、続きから再開します。

## macOSに「開発元を確認できない」と表示された場合

配布物へ電子署名・公証をしていない場合に限り、初回だけ表示されることがあります。配布者が署名済みパッケージとして提供すれば、この操作も不要になります。

## Windows DefenderまたはSmartScreenが表示された場合

未署名のZIPをインターネットから取得した場合に表示されることがあります。配布者がコード署名済みパッケージとして提供すれば、この警告も不要になります。講師から直接受け取った配布物以外は実行しないでください。
