# Codex用：山岳編集の実行記録

- 戸沢村のMaster.mdはPhase 1原稿で、ASSET番号を持たない。Asset_Prompts_Full.mdを対応表にし、本文を装飾除去後に全298行照合してから編集用素材台本を派生する。元原稿・プロンプトは変更しない。
- 仮TTSへMarkdown太字やHTMLコメントを渡さない。原稿本文と発話本文を分ける。行別の実音声サンプル境界はASRと偽らず、`--timings`で扱い、完成時は別途ASRで照合。
- 素材の存在だけで意味の一致とはしない。短尺の自動結合によって冒頭の「このクマ」の場面が村の俯瞰へ変わったため、戸沢村では指定素材がある行を優先して復元する。
- 地形ツールの既定座標が別事件の場所になっていないか、実座標と出力を確認。戸沢村は`map_renderer: tozawa_v1`で専用の固定経路へ送る。プレビュー・全体再構成・別PCの配布物で同じ経路を使う。非公表の事故地点を実座標ピンとして創作しない。
- launchdのBackground/Adaptive優先度で描画ワーカーがPRI20・CPU数%へ落ちた実例あり。今回の編集ジョブは`ProcessType: Interactive`でPRI31・CPU約90%へ戻った。生存だけを「順調」とせず、成果物の更新とログを確認する。
- 取得に失敗した地形タイルを欠損色で埋めて完了扱いにしない。今回ASSET-100の57/64枚取得を検出し、再試行で全数取得して再開した。
- GitHubは無関係な未公開ローカルコミットを混ぜない。origin/main起点の専用worktreeから今回分だけをpush。大きい素材は既存の下書きReleaseへ置き、アップロード後のサイズとGitHub側SHA-256を照合。
- 別PC用には相対パスの素材・shots.json・音声・全カットシート・再生クリップ・専用ツール・Mac/Windows起動口をまとめる。閲覧用セットアップでAIのインストールやログインを強制しない。認証トークン・ブラウザ履歴・署名URL・生成受付JSONは含めない。
- 自動検査PASS、AIの一覧/コマ確認、本人の最終確認を分けて記録。BGM・SE・地図注記など未実施の演出があれば、確認版と明記し、公開版として完成したとは報告しない。

共有のCLAUDE.md・Claude用スキルへは書き戻さない。

- 編集指示の最初の引用を無条件にテロップ採用しない。「約○mではなく」「死因失血ではなく大量出血」の否定例、比較用の正常、切替前1988年を誤表示した。否定・比較・時間切替の文脈を目視で確認し、確定表示を戸沢村prepare.pyへ保存。冒頭の問いは1行の文字数が画面幅へ収まるか実フレームを確認。

全編の処理状態は素材フォルダの `.editing/status.json`、保存状態は `.editing/delivery_status.json`。`run.py` は検査合格後に確認版を出力し、`publish.py --wait` は自動検査の合格後に確認版を下書きReleaseへ保存する。AIの目視記録の有無は別途記録し、未実施なら未実施と明記する。チャット再開を必要とする手動フラグを確認版の保存条件にしない。書き出しと転送中はMacのスリープを抑止し、終了すると解除する。

- launchdは対話シェルのPATHを継承しない。GitHub転送はghの絶対パスを解決し、常駐ジョブの実環境でも起動を確認する。
