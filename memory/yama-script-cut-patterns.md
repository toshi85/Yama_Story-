### 学習ポイント

1. **「対比演出だけのセクション」はカットされやすい**
   - §5（場面転換）・§11（同じ山別の運命）は描写中心で本筋に必須でない
   - → 次回台本: 対比演出は独立セクションにせず、隣接セクションに織り込む

2. **「教訓・もし系」はエンディングに統合される**
   - §22「もし」§24「教訓」§23「1年後の沈黙」のうち、§23のみ残り §22/§24 はカット
   - → 次回台本: 教訓系は1セクション（§23相当）に集約し、独立した「もし」「教訓」は作らない

3. **「事件のクライマックスの細分化」はカット対象**
   - §7「馬乗り」§8「大原反撃」§9「阿部転落」は連続だが §8 がカット
   - → 次回台本: 戦闘シーンは「襲撃→反撃→決着」の3段で十分。中間の細分化は避ける

4. **「核心キーワードを先に出す」順序入替が好まれる**
   - §13「土と枝」→ §14「保存食」を逆順に変更
   - → 次回台本: フック性の高いキーワード（「保存食」「人災」等）を先に提示→科学的解説で裏付ける構造を初稿から採用

5. **動画尺25分前後が想定なら、台本は約25-30セクション**で十分
   - Narration_Only.md 25セクション → カット6個 → 動画17セクション
   - → 次回台本: 25-30セクションを上限とし、各セクションの必要性をフィルタリング
