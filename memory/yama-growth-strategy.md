## 背景
- 2024年10月（トムラウシ）を最後に約1年4ヶ月休止
- 底（月6.3万再生/$369）から2026年2月に投稿再開
- 2026-03-23時点: 月19.9万再生 / ¥146,978 / 登録者20,900人 / 動画34本 / CPM $4.59
- トラフィック: 登録者62% + 関連動画28% + 検索3.5%（YouTube内部循環90%）
- 新規動画はまだインプレッション制限中（アルゴリズム信頼回復の途上）

## コンテンツ方針（2026-03-23 データ分析確定）

### 再現可能な勝ちパターン2軸（交互投稿）
1. **クマ事件**（最優先） — チャンネル再生の70%以上がクマ関連。アルゴリズムに「クマチャンネル」と認識されている
   - 福岡大368万、熊倉山140万、十和利山68万 = Top3すべてクマ
   - 候補: 大雪山SOS、最近のクマ被害（2024-2025年）
2. **「舐めた人間」× 具体的ディテール** — 視聴者が「こいつヤバい」と思える装備・判断ミス
   - サンダル42万、稲村ヶ岳17万、新潟親子26万
   - 具体物（サンダル・焼肉のタレ等）or 具体数字（6歳・4人家族）がフックに必須

### 伸びないパターン（避ける）
- 「登山者が遭難して死亡」だけでツッコミどころがない事件
- フックが弱いタイトル（トムラウシ1.9万、富士山0.9万）
- 有名事件でもディテール不足なら回らない

### Shorts方針
- AI全自動パート分割は**継続**（コストゼロ + マルチプラットフォーム素材として活用）
- 最低1〜2ヶ月回して判断。伸びなければ本編クライマックス切り出し方式に変更

### 睡眠用・総集編
- 睡眠用はメンバーシップ限定コンテンツとして運用（一般公開の再生数は指標外）
- 総集編を月1本追加（低コスト高リターン）

## Phase 1: 復帰の勢いを止めない（〜2026-04）
- **週1本ペースを死守**（最低4週連続）。クオリティより継続性
- 次の1本はクマ事件を優先
- 福岡大ヒグマのサムネCTR改善（中間テキスト消去）

## Phase 2: 安定軌道（2026-04〜06）
- 勝ちパターン2軸を交互投稿
- 既存34本の終了画面・カードを全更新（関連動画28%の最適化）

## Phase 3: 月30万再生安定（2026-06〜09）
- 理想投稿頻度: 本編週1 + 総集編月1 = 月5本

## やらないこと
- 海外展開・翻訳（99%日本、CPM十分）
- SEO最適化（検索流入3.5%、関連動画+登録者が主戦場）
