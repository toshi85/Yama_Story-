## データ取得方法（再現性確保）

```bash
# 全動画リスト取得（yt-dlpのflat-playlistでは再生数取れない）
yt-dlp --flat-playlist --dump-json --no-warnings "https://www.youtube.com/@zikolog/videos"

# 個別動画の完全メタデータ取得（再生数含む）
for vid in c_kkIsQlFe8 -sHkcezuQLY Ot4G3-EHj5Q ...; do
  yt-dlp --no-warnings --dump-json --skip-download "https://www.youtube.com/watch?v=$vid"
done

# Playwright MCPでチャンネルページの動的読み込み完了後のsnapshot取得
mcp__playwright__browser_navigate(url="https://www.youtube.com/@zikolog/videos")
mcp__playwright__browser_snapshot()
```

**Why:** 動画IDの誤認はweekly_analystレポートの信頼性を根底から損なう。さらに、APIデータには公開直後の初動が含まれない（2-3日遅延）ため、新作初動の評価には直接Web取得が必須
**How to apply:** 週次レポート前 + 投稿後3日以内の初動評価時に必ず本ファイルと照合
